# QuietShield 2.4.2

QuietShield 2.4.2 improves Private Browser video fullscreen, monthly data reporting, and family website access requests.

## Highlights

- YouTube and HTML5 video can enter and exit fullscreen inside QuietShield.
- The Data usage screen separates current-month Wi-Fi and mobile usage.
- Mobile Data is hidden when unsupported or empty.
- Managed children can request parent review of a blocked website.
- Parents can allow once, always allow, or deny.
- No VLC, Media3, ExoPlayer, or bundled codec library was added.
