# QuietShield 2.4.1 release notes

QuietShield 2.4.1 improves mobile-data reporting, notification consistency, stability, activation handling, Private Browser behavior, scrolling, and privacy.

Highlights:
- Mobile Data Usage remains available while connected to Wi-Fi.
- Wi-Fi-only devices show a clear empty state.
- QuietShield is excluded from the ordinary per-app usage ranking.
- Android's overall mobile-data total remains unchanged.
- Samsung tablets use the same notification icon resource as Honor.
