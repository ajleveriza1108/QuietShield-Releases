# QuietShield 2.4.5 Beta 1 — Code 261

This phone-and-tablet beta adds:

- Movable, icon-only fullscreen lock.
- Correct video Fit and Fill handling.
- Picture-in-Picture floating video.
- Premium video settings and adaptive quality preference.
- Secure Sign-In Guard for unsafe networks.
- Privacy-preserving possible-sign-in warning outside the Private Browser.
- App Connection Lock filters:
  - All apps
  - Blocked
  - Wi-Fi only
  - Mobile data only
  - Wi-Fi and mobile data

## Beta notice

This is a prerelease for device testing. It does not replace the stable
QuietShield update feed. Android TV is not included in this beta.
